# Proposal Types

Curriculum proposals are grouped into four types based on the scope of change. These are not rigid categories — they are practical guides for preparing a proposal and setting expectations for the depth of review. The goal is to help everyone spend time on the right things.

| Type | Typical Examples | Review Posture |
|---|---|---|
| **Cosmetic change** | Title corrections, catalog text edits, administrative updates — nothing substantive is changing | Confirm accuracy, consistency, and absence of unintended downstream effects. |
| **Course change** | New course, course modification, course deactivation | Review curricular rationale, catalog clarity, student impact, and related course or program effects. |
| **Program change** | Requirement changes, plan changes, substantial revisions to existing programs | Review advising, degree progress, resources, assessment/APR/accreditation links, and cross-unit implications. |
| **New program** | New degree, certificate, credential, or major restructuring | Review strategic fit, demand, duplication/collaboration, resources, implementation, and institutional commitments. |

## What Proposal Type Determines

Proposal type shapes two things: how much preparation is expected before submission, and where reviewers focus attention.

- A **cosmetic change** involves no substantive curricular shift — nothing about requirements, learning outcomes, or program structure is changing. It should move quickly; reviewers confirm accuracy and the absence of unintended downstream effects.
- A **course change** requires enough documentation for reviewers to evaluate academic rationale, catalog effects, and student impact.
- A **program change** requires early consultation — including Associate Dean engagement — before formal submission.
- A **new program** requires concept-level work, including a Provost-level concept discussion, before a Kuali submission is appropriate.

**Not sure which type fits?** Start with the scope of the change. A correction is a cosmetic change. A new requirement is a program change. When the boundary is genuinely unclear, check with your department curriculum committee or Associate Dean before getting into the Kuali weeds.
